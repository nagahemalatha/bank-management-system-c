# Bank Management System in C

## 📌 Project Description

The Bank Management System is a console-based application developed using the C programming language. It provides basic banking operations such as account creation, deposits, withdrawals, balance checking, money transfers, and transaction management.

## 🚀 Features

- Create a new bank account
- Account login and authentication
- Deposit money
- Withdraw money
- Check account balance
- Transfer money between accounts
- View transaction details
- Account management
- Basic security features
- File handling for storing data

## 🛠️ Technologies Used

- C Programming Language
- Structures
- Functions
- File Handling
- Standard C Libraries

## 💻 How to Run

1. Download or clone this repository.
2. Open `bank_management_final.c` in a C compiler or IDE.
3. Compile the program.
4. Run the generated executable.
5. Follow the instructions displayed in the console.
